# 复旦MBA 薄荷4班 · 班级网站

> 2026 级复旦大学 MBA 薄荷 4 班班级网站 ·「4 the Best, for the Future」

## 网站地址

- 正式站：**https://mint4.cn**
- 备用域名：https://mint4.pages.dev

## 功能一览

- 🏠 **首页**：Bento 卡片式首页，实时展示下节课/作业待办、下一场活动、班费余额、最新公告与未读提醒；生日当天全屏祝贺
- 📅 **活动日历**：月历 / 时间线双视图，活动报名与名额显示，支持固定活动、每周重复、中外节日（含农历/节气）与 ICS 日程导出
- 🙏 **许愿池**：朋友圈式互动，文字 + 最多 3 张图，实名点赞与评论
- 📊 **班级投票**：实名/匿名、多选、图文选项，登录后参与
- 📢 **公告通知**：分类置顶、重要标记，多语言
- 📚 **课程资料 / 知识库**：课件、作业、参考资料按讲次排序，最新在最上；课程笔记持续更新
- 💰 **班费公开**：收支明细公开透明；预算公示（全员发起、公示投票、自动结算）、报销流程、财务工作台
- 🌱 **薄荷币**：班级虚拟积分（薄荷园/排行榜/成长森林/荣誉墙），审批公示，不可兑换现金
- 🖼️ **活动相册**、🌍 **城市足迹**（IP 点亮中文城市名）、🌳 **匿名树洞**（实名/匿名可选，踩一踩、评论互动）、👥 **同学名录**（按组展示）
- 🎂 **生日祝贺**：当天寿星全屏烟花庆祝（农历/公历自动换算）
- 📝 **入学测试题库**、🛠️ **实用小工具**、🗺️ **复旦活动雷达**（外链）
- 🔐 **实名账户体系**：注册登录、个人资料、班委管理后台（角色权限管理）
- 🌐 中文 / English / ภาษาไทย 三语；🌙 深色模式（跟随系统）

## 使用说明

- 同学使用班级账号（用户名 + 真名）注册登录，即可参与投票、活动报名、许愿池、预算公示与报销等。
- 内容（公告/活动/投票/班费/课件/知识库/相册等）由各班委通过管理后台发布与维护。
