# โครงสร้าง

## ภาพรวมสถาปัตยกรรม

ชั้นเรียนใช้สถาปัตยกรรมการปกครองแบบแบนของ**หกโมดูลหน้าที่** โดยมี"หัวหน้าชั้นเรียน + รองหัวหน้า"เป็นแกนกลางการประสานงาน และห้าโมดูลหน้าที่ทำงานคู่ขนานกัน แต่ละโมดูลทำงานอย่างอิสระในขณะที่ทำงานร่วมกับคนอื่น

## หกโมดูลหน้าที่

| โมดูลหน้าที่ | การจัดตั้งบุคลากร | หน้าที่หลัก | จุดเข้าเว็บไซต์ |
|------------|----------------|------------|--------------|
| **หัวหน้าชั้นเรียน** | 1 คน | ประสานงานกับมหาวิทยาลัย ประสานงานโดยรวม จับคู่ทรัพยากรข้ามกลุ่ม กรองข้อมูล | [ประกาศ](/th/announcements/) |
| **รองหัวหน้า** | 2 คน | งานประจำวัน จัดการการประชุมคณะกรรมการ ปฏิทินงาน ติดตามความคืบหน้า | [ประกาศ](/th/announcements/) |
| **เจ้าหน้าที่ประสบการณ์** | 2 คนขึ้นไป | ฟอกฟันกิจกรรม ข้อมูลไลฟ์สไตล์ ดูแลบรรยากาศชั้นเรียน ทุกคนถูกมองเห็น | [กิจกรรม](/th/activities/) |
| **เจ้าหน้าที่การเงินและส่งเสริม** | 2 คนขึ้นไป | เงินชั้นเรียนโปร่งใส เปิดเผยสมุดบัญชี ระบบเหรียญชั้นเรียน งบประมาณและส่งเสริม | [การเงิน](/th/finance/) |
| **ผู้ดูแลความทรงจำ** | 2 คนขึ้นไป | บันทึกภาพ ผลิตเนื้อหา สร้างแบรนด์ชั้นเรียน ผลิตสิ่งของ | [ความทรงจำ](/th/gallery/) |
| **นักวิจัยความรู้** | 2 คนขึ้นไป | แยกแยะหลักสูตร คลังความรู้ ส่งเสริมด้วยเครื่องมือ AI จัดหาทรัพยากรการเรียนรู้ | [คลังความรู้](/th/knowledge/) · [ไฟล์บรรยาย](/th/slides/) |

## การทำงานร่วมกันระหว่างโมดูล

### ชั้นประสานงานหลัก

**หัวหน้าชั้นเรียน + รองหัวหน้า**เป็นแกนกลางการประสานงาน รับผิดชอบ:

- เรียกประชุมคณะกรรมการและซิงโครไนซ์ความคืบหน้าของโมดูล
- ประสานงานรายการความร่วมมือข้ามโมดูล
- กำหนดจังหวะและลำดับความสำคัญโดยรวมของชั้นเรียน
- ทำหน้าที่เป็นช่องทางการสื่อสารระหว่างมหาวิทยาลัยและชั้นเรียน

### เมทริกซ์การทำงานร่วมกัน

| สถานการณ์การทำงานร่วมกัน | โมดูลที่มีส่วนร่วม | วิธีการทำงานร่วมกัน |
|------------------------|-----------------|-------------------|
| วางแผนและดำเนินกิจกรรมชั้นเรียน | เจ้าหน้าที่ประสบการณ์ + ผู้ดูแลความทรงจำ + เจ้าหน้าที่การเงิน | เจ้าหน้าที่ประสบการณ์วางแผน ผู้ดูแลความทรงจำบันทึก เจ้าหน้าที่การเงินรับประกันงบประมาณ |
| การรวบรวมความรู้หลักสูตร | นักวิจัยความรู้ + ผู้ดูแลความทรงจำ | นักวิจัยความรู้แยกแยะเนื้อหา ผู้ดูแลความทรงจำผลิตสื่อภาพ |
| สร้างแบรนด์ชั้นเรียน | ผู้ดูแลความทรงจำ + เจ้าหน้าที่ประสบการณ์ | ผู้ดูแลความทรงจำนำภาพแบรนด์ เจ้าหน้าที่ประสบการณ์ผสานเข้ากับประสบการณ์กิจกรรม |
| ส่งเสริมและยอมรับนักเรียน | เจ้าหน้าที่การเงิน + เจ้าหน้าที่ประสบการณ์ + รองหัวหน้า | เจ้าหน้าที่การเงินจัดหาสิ่งของ เจ้าหน้าที่ประสบการณ์ค้นพบจุดเด่น รองหัวหน้าติดตาม |
| เผยแพร่และสื่อสารข้อมูล | หัวหน้าชั้นเรียน + รองหัวหน้า + ทุกโมดูล | หัวหน้ากำหนดน้ำเสียง รองหัวหน้าจัดการ ทุกโมดูลจัดหาเนื้อหา |

## แผนที่ฟังก์ชันเว็บไซต์

เว็บไซต์ชั้นเรียนเป็น**พื้นที่ทำงานดิจิทัล**ของหกโมดูลหน้าที่ โดยแต่ละโมดูลมีช่องออนไลน์ที่สอดคล้องกัน:

| โมดูลหน้าที่ | หน้าที่สอดคล้อง | ฟังก์ชันหน้า |
|------------|---------------|------------|
| หัวหน้าชั้นเรียน / รองหัวหน้า | [ประกาศ](/th/announcements/) | เผยแพร่แจ้งเตือนชั้นเรียน รายการสำคัญ การสื่อสารจากมหาวิทยาลัย |
| เจ้าหน้าที่ประสบการณ์ | [กิจกรรม](/th/activities/) | ปฏิทินกิจกรรม รีวิวกิจกรรม การจัดการลงทะเบียน |
| เจ้าหน้าที่การเงินและส่งเสริม | [การเงิน](/th/finance/) | สมุดบัญชีเงินชั้นเรียน เปิดเผยรายรับรายจ่าย คำอธิบายงบประมาณ |
| ผู้ดูแลความทรงจำ | [ความทรงจำ](/th/gallery/) | กำแพงรูปภาพ ไฮไลท์วิดีโอ ช่วงเวลาชั้นเรียน |
| นักวิจัยความรู้ | [คลังความรู้](/th/knowledge/) | บันทึกหลักสูตร การจัดระเบียบวิชา วิธีการเรียนรู้ |
| นักวิจัยความรู้ | [ไฟล์บรรยาย](/th/slides/) | สไลด์หลักสูตร เอกสารอ่านประกอบ ทรัพยากรเสริม |
| คณะกรรมการทั้งหมด | [คณะกรรมการ](/th/governance/) | ปรัชญาการปกครอง หน้าที่โมดูล รายชื่อสมาชิก |
| คณะกรรมการทั้งหมด | [โครงสร้าง](/th/about/structure/) | คำอธิบายสถาปัตยกรรม ความสัมพันธ์การทำงานร่วมกัน แผนที่ฟังก์ชัน |
| หัวหน้าชั้นเรียน | [รายชื่อ](/th/directory/) | ข้อมูลนักเรียน การแจกแจงอุตสาหกรรม รายละเอียดการติดต่อ |
| นักเรียนทุกคน | [ตารางเรียน](/th/schedule) | ตารางหลักสูตร เวลาเรียน ข้อมูลห้องเรียน |

## หลักการปกครอง

1. **แบบแบน**: ไม่มีอุปสรรคตามลำดับชั้น — นักเรียนใดก็สามารถติดต่อหัวหน้าโมดูลใดก็ได้โดยตรง
2. **โปร่งใส**: กระบวนการตัดสินใจและข้อมูลการเงินทั้งหมดเปิดเผยต่อชั้นเรียนทั้งหมด
3. **เน้นการบริการ**: คณะกรรมการมีอยู่เพื่อให้บริการนักเรียน ไม่ใช่เพื่อจัดการพวกเขา
4. **ทำซ้ำ**: กลไกการปกครองได้รับการปรับปรุงอย่างต่อเนื่องตามความต้องการจริงของชั้นเรียน

> สถาปัตยกรรมนี้ปัจจุบันเป็นเวอร์ชันข้อความ จะมีการเพิ่มแผนภาพสถาปัตยกรรมที่มองเห็นได้ในภายหลัง
