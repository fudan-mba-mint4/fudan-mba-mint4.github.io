# 职能架构

## 架构总览

班级采用**六大职能模块**的扁平化治理架构，以"班级主理人 + 副主理人"为协调核心，五大职能模块并行运作，各模块之间既独立负责又协同联动。

## 六大职能模块

| 职能模块 | 人数配置 | 核心职责 | 网站入口 |
|---------|---------|---------|---------|
| **班级主理人** | 1 人 | 学院对接、全局统筹、跨组资源撮合、信息降噪 | [公告](/announcements/) |
| **副主理人** | 2 人 | 日常事务、班委会组织、事项日历、进度跟进 | [公告](/announcements/) |
| **体验运营官** | 2 人以上 | 活动孵化、生活情报、班级氛围维护、人人被看见 | [活动](/activities/) |
| **财务激励官** | 2 人以上 | 班费透明、台账公示、班级币体系、预算与激励 | [班费](/finance/) |
| **记忆主理人** | 2 人以上 | 影像记录、内容输出、班级品牌建设、物料产出 | [回忆](/gallery/) |
| **智库研究员** | 2 人以上 | 课程拆解、知识库建设、AI 工具赋能、学习资源供给 | [知识库](/knowledge/) · [课件下载](/slides/) |

## 模块间协作关系

### 核心协调层

**班级主理人 + 副主理人**构成协调核心，负责：

- 召集班委会，同步各模块进展
- 协调跨模块合作事项
- 把握班级整体节奏和优先级
- 作为学院与班级之间的联络通道

### 模块协作矩阵

| 协作场景 | 参与模块 | 协作方式 |
|---------|---------|---------|
| 班级活动策划与执行 | 体验运营官 + 记忆主理人 + 财务激励官 | 体验运营官策划，记忆主理人记录，财务激励官保障预算 |
| 课程知识沉淀 | 智库研究员 + 记忆主理人 | 智库研究员拆解内容，记忆主理人产出可视化物料 |
| 班级品牌建设 | 记忆主理人 + 体验运营官 | 记忆主理人主导品牌视觉，体验运营官融入活动体验 |
| 同学激励与认可 | 财务激励官 + 体验运营官 + 副主理人 | 财务激励官提供物资，体验运营官发现亮点，副主理人跟进落地 |
| 信息发布与传达 | 班级主理人 + 副主理人 + 各模块 | 主理人定调，副主理人组织，各模块提供内容 |

## 治理原则

1. **扁平化**：没有层级壁垒，任何同学都可以直接联系任何模块负责人
2. **透明化**：所有决策过程和财务信息对全班公开
3. **服务化**：班委的存在是为了服务同学，而非管理同学
4. **迭代化**：治理机制持续优化，根据班级实际需求调整
