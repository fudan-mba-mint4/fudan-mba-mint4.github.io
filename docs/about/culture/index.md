# 班级文化

## 班级口号

<div style="text-align:center; padding: 2rem 0; font-size: 2rem; font-weight: 700; color: var(--vp-c-brand-1);">

4 the Best, for the Future.

</div>

这句口号既是对"4 班"的巧妙嵌入，也表达了我们追求卓越、面向未来的共同信念。

## 核心价值观

### 学习成长

以开放心态持续学习，在 MBA 旅程中不断突破认知边界，将课堂知识转化为实践能力。

### 资源共享

每个人都是资源的贡献者和受益者。我们倡导信息互通、经验分享、机会共建，让集体智慧放大个体价值。

### 团结互助

同学之间真诚相待、彼此支持。无论是学业压力还是生活挑战，我们都是彼此最可靠的伙伴。

### 追求卓越

不满足于"差不多"，在每一件事上追求更高标准。卓越不是终点，而是我们共同的生活方式。

## 班徽含义

班徽是班级身份的视觉象征，每一个元素都承载着特定寓意：

| 元素 | 寓意 |
|------|------|
| **圆形徽章** | 象征团结与完整，代表班级是一个紧密相连的整体 |
| **帆船图案** | 寓意扬帆起航、乘风破浪，象征 MBA 旅程的探索精神 |
| **薄荷绿主题色** | 代表清新、活力与成长，呼应"薄荷"班级名称 |
| **"FUDAN UNIVERSITY"** | 标明所属院校，体现复旦人的身份认同 |
| **"MBA 2026"** | 标注届别，记录我们共同的两年时光 |

## 班级名称由来

### 薄荷 4 班（Mint 4）

"薄荷"象征清新、活力与成长——正如我们这群在职业发展关键阶段选择重返校园的同学，带着对新知的渴望和对未来的期许，在复旦 MBA 的课堂上重新出发。

薄荷绿是我们的主题色，它既不过于张扬，又充满生命力，恰如我们班级的气质：低调但有力量，温和但有方向。

"4"不仅是班级编号，更与口号"4 the Best"形成谐音双关，寓意我们追求最好的自己、最好的班级、最好的未来。

## 文化氛围

我们致力于营造一个**真诚、开放、温暖、向上**的班级氛围：

- **真诚**：不装、不端，以真实面目相处
- **开放**：包容不同背景和观点，鼓励多元表达
- **温暖**：彼此关心、互相托底，让每个人都有归属感
- **向上**：互相激励、共同进步，不让任何一个人掉队

在这里，每个人都能**被看见、被需要、被记得**。
