# 班委介绍

## 班级治理理念

> **班委不是管理者，是生态赋能者 —— 每个同学都能被看见·被需要·被记得**

我们相信，一个优秀的班级不是靠少数人"管理"出来的，而是靠一套赋能机制让每个人都能参与、贡献和成长。班委的角色是搭建平台、降低协作成本、激活个体能量，而非自上而下的指令传达。

## 六大职能模块

班级治理由六大职能模块构成，覆盖学习、活动、财务、记忆、研究和全局统筹等维度。

### 班级主理人（1 人）

- **学院对接**：作为班级与学院之间的官方联络人，传达学院要求，反馈班级诉求
- **全局统筹**：把握班级整体发展方向，协调各模块工作节奏
- **跨组资源撮合**：在不同职能模块、不同同学之间牵线搭桥，促进资源流动
- **信息降噪·定调学期氛围主题**：过滤冗余信息，为每个学期设定核心氛围与主题

### 副主理人（2 人）

- **日常事务·进度跟进**：处理班级日常运营事务，跟踪各项工作的执行进度
- **班委会组织**：定期组织班委会，确保各模块信息同步、问题及时解决
- **事项日历·跟进落地进度**：维护班级事项日历，确保重要事项不遗漏、有闭环

### 体验运营官（2 人以上）

- **活动孵化·生活情报**：策划和组织班级活动，收集并分享同学生活相关信息
- **班级氛围维护**：关注班级整体情绪与氛围，及时调节和引导
- **人人被看见·引导沉默同学发声**：特别关注较少发言的同学，创造机会让每个人都能被看见和听见

### 财务激励官（2 人以上）

- **班费透明·台账公示**：管理班费收支，定期公示台账，确保财务完全透明
- **班级币体系运营**：设计和运营班级内部激励积分体系，鼓励正向行为
- **预算机制·小额激励物资**：建立班级预算机制，采购小额激励物资，认可同学贡献

### 记忆主理人（2 人以上）

- **影像记录·内容输出**：记录课堂、活动和日常瞬间，产出照片、视频等内容
- **班级品牌建设**：塑造和传播班级品牌形象，提升班级辨识度和凝聚力
- **物料产出·结合班级文化**：设计和制作班级周边物料，融入班级文化元素

### 智库研究员（2 人以上）

- **课程拆解·知识库**：梳理和拆解课程内容，建设和维护班级知识库
- **AI 工具·学习赋能**：探索和推广 AI 工具，提升全班学习效率
- **学习资源·按同学需求供给**：根据同学实际需求，精准供给学习资源和方法
