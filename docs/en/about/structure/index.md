# Org Structure

## Architecture Overview

The class adopts a flat governance architecture of **six functional modules**, with "Class Lead + Deputy Leads" as the coordination core and five functional modules operating in parallel. Each module operates independently while collaborating with others.

## Six Functional Modules

| Functional Module | Staffing | Core Responsibilities | Website Entry |
|------------------|----------|----------------------|--------------|
| **Class Lead** | 1 person | School liaison, overall coordination, cross-group resource matching, information filtering | [Announcements](/en/announcements/) |
| **Deputy Leads** | 2 persons | Daily affairs, committee organization, task calendar, progress tracking | [Announcements](/en/announcements/) |
| **Experience Officers** | 2+ persons | Activity incubation, lifestyle intel, class atmosphere maintenance, everyone is seen | [Activities](/en/activities/) |
| **Finance & Incentive Officers** | 2+ persons | Transparent class fund, ledger disclosure, class coin system, budget & incentives | [Finance](/en/finance/) |
| **Memory Curators** | 2+ persons | Visual recording, content output, class brand building, material production | [Memories](/en/gallery/) |
| **Knowledge Researchers** | 2+ persons | Course breakdown, knowledge base, AI tool empowerment, learning resource supply | [Knowledge Base](/en/knowledge/) · [Slides](/en/slides/) |

## Inter-Module Collaboration

### Core Coordination Layer

**Class Lead + Deputy Leads** form the coordination core, responsible for:

- Convening committee meetings and syncing module progress
- Coordinating cross-module collaboration items
- Setting the overall class pace and priorities
- Serving as the communication channel between the school and the class

### Collaboration Matrix

| Collaboration Scenario | Participating Modules | Collaboration Method |
|----------------------|---------------------|---------------------|
| Class activity planning & execution | Experience Officers + Memory Curators + Finance Officers | Experience Officers plan, Memory Curators record, Finance Officers ensure budget |
| Course knowledge consolidation | Knowledge Researchers + Memory Curators | Knowledge Researchers break down content, Memory Curators produce visual materials |
| Class brand building | Memory Curators + Experience Officers | Memory Curators lead brand visuals, Experience Officers integrate into activity experience |
| Student incentive & recognition | Finance Officers + Experience Officers + Deputy Leads | Finance Officers provide items, Experience Officers spot highlights, Deputy Leads follow up |
| Information publishing & communication | Class Lead + Deputy Leads + All modules | Lead sets tone, Deputy Leads organize, modules provide content |

## Governance Principles

1. **Flat**: No hierarchical barriers — any student can directly contact any module lead
2. **Transparent**: All decision-making processes and financial information are open to the entire class
3. **Service-oriented**: The committee exists to serve students, not to manage them
4. **Iterative**: The governance mechanism is continuously optimized based on actual class needs
